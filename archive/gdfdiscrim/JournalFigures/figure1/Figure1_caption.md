**Figure 1 | Plasma GDF15 discriminates PVOD from IPAH and HPAH; no other variable measured in the cohort does.**

Receiver-operating-characteristic curves for separating PVOD (n = 26) from the pooled IPAH (n = 98) and HPAH (n = 42) cohorts, for each variable available in the same 166 patients. One panel per variable, ordered by area under the curve (AUC); the final panel overlays all seven. The dashed diagonal is the line of no discrimination (AUC 0.5). AUC is given in each panel with a 95% confidence interval from 4,000 stratified bootstrap resamples, drawn independently within the PVOD and the comparator groups so that group sizes are preserved. Marker n differs because the underlying measurements are unevenly complete; n and the number of PVOD cases contributing are given in each panel, and every curve and AUC is computed only on the patients with that measurement. AUCs are direction-free — each variable is oriented to whichever direction discriminates better, decided once on the full sample and then held fixed across all bootstrap replicates. That convention favours the weak markers, since the more favourable of two directions is chosen after seeing the data; they remain near 0.5 regardless. GDF15 reaches AUC 0.956 (0.912–0.989), while the best of the remaining variables, 6MWD, reaches only 0.673 and the weakest 0.522; the confidence interval includes 0.5 for 4 of the 6 non-GDF15 variables, so their discrimination is not distinguishable from chance in this sample. No multiplicity adjustment is applied across the seven markers and no marker is combined with another; each interval describes one variable in isolation. AUC point estimates are those established in the project analysis and are reproduced exactly here. Each AUC uses one variable together with the diagnostic label only, so no patient-level pairing between GDF15 and any clinical variable is involved. Source data: Prabhakar et al., J Clin Invest 2026;136(2):e199159, Supplementary Source Data — GDF15 from sheet Fig_1a (panel Fig. 1a); age and the clinical variables from the per-patient panels Fig_1g–Fig_1m.
